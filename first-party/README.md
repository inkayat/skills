# First-party skills

This area is reserved for future original skills. No original skill is distributed in this candidate. The former experimental minimal-change and faithful-editing candidates are preserved privately, not repackaged here.

A future original belongs in `<name>/SKILL.md` with conventional name/description frontmatter, its actual supporting references and an explicit license/provenance declaration. Keep upstream copies under `upstream/`; do not edit them into local forks. Any future authoring, behavioral evaluation or consumer activation needs its own authorized task.

The upstream updater never reads, traverses, rewrites or removes this directory.
